# GuitApp 💰📊📈
Gestor de finanzas personales

## 🚀 Tecnologías
- React + Vite
- Supabase (autenticación y base de datos)
- CSS / Tailwind

## 📂 Funcionalidades
- Registro de ingresos y gastos
- Visualización por mes o año
- Gráficos interactivos
- Autenticación segura con Supabase

## ⚙️ Instalación
```bash
pnpm install
pnpm dev
